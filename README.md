# Progress City

Локальное приложение для обучения, проектов и привычек. Главный экран — редактируемый изометрический город. В одном учебном направлении можно вести несколько исследований: у каждого свои материалы, постройка и этап развития, а очки общие. Снятие здания с карты сохраняет его содержимое.

Текущий план завершения: [ROADMAP](docs/ROADMAP.md); проверенное состояние: [STATUS](docs/STATUS.md). После конфликта настроек направления ваш ввод остаётся в форме. Скопируйте нужное и нажмите **«Загрузить актуальное направление»**, затем сохраните изменения заново. Ошибка сохранения не показывает успешный статус. Повреждённый или обрезанный ZIP отклоняется до замены города; собственные полные архивы прежних версий поддерживаются.

## Ежедневный запуск на Windows

Нужен Node.js 22.12+ с npm. Проверено на Windows с Node **22.23.2**, npm **12.0.2**. Docker, backend, ключи и права администратора не нужны. Ничего глобально устанавливать или менять в настройках Windows скрипты не будут.

1. Один раз после получения или обновления приложения запустите **`Prepare Progress City.cmd`** из папки проекта. Он готовит отдельную сборку. Если зависимости ещё не установлены, выполните в терминале `& '.\Prepare Progress City.cmd' --install`: это явная установка по существующему lockfile.
2. Для обычной работы дважды нажмите **`Start Progress City.cmd`**. Он открывает подготовленную версию без установки и сборки. Повторный Start использует свой уже запущенный сервер.
3. Сохраните работу, затем запустите **`Stop Progress City.cmd`**. Город остаётся в браузере. Следующий Start вернёт сохранённую работу.

Адрес остаётся **http://127.0.0.1:5173/**. Откройте его в прежнем браузере и профиле: `localhost`, другой порт и другой профиль имеют отдельное хранилище. Start вызывает браузер по умолчанию; если город был в другом браузере, откройте тот же адрес в нём вручную. Автотесты не запускались на личном порту 5173.

Если на 5173 работает прежний `npm run dev`, завершите его в том терминале, где запускали. Start не убивает чужие процессы и не меняет порт. Отсутствующий Node/npm, неподготовленная или устаревшая сборка объясняются в окне команды. При отсутствии npm в PATH поддерживается уже существующий локальный `.tools/package/bin/npm-cli.js`; скрипты сами его не скачивают.

Обновление: сохраните работу и полный архив города → Stop → обновите файлы → Prepare → Start. Prepare не заменяет активную сборку; неудачная подготовка сохраняет предыдущую. Версия сборки видна внизу боковой панели. Служебные файлы и подготовленные версии лежат в игнорируемой `.progress-city/`, без заметок. Откат кода не откатывает базу. Сервер раздаёт только сборку на loopback, не исходники и не содержимое профиля. После Stop загрузка страницы недоступна до следующего Start.

## Запуск для разработки

Нужен Node.js 22.12+; текущая итерация проверена на Windows с Node **22.23.2**, предыдущая итерация кварталов — с **24.19.0**. Docker, backend и API-ключи не нужны.

```powershell
cd C:\ProjectsForSelf\ProgressCity
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173**. Всегда используйте тот же адрес и порт: IndexedDB привязана к origin. `localhost` и `127.0.0.1`, а также разные порты имеют отдельные базы.

В среде текущей реализации `npm` отсутствовал в PATH. Для неё подготовлен локальный npm в игнорируемой папке `.tools/package`:

```powershell
node .tools/package/bin/npm-cli.js ci
node .tools/package/bin/npm-cli.js run dev
```

Это необязательная адаптация среды. После обычной установки Node с npm используйте стандартные команды выше. Глобальные настройки проекта не менялись.

## Как пользоваться

### Черновики, библиотека и рост привычки

Изменённый ввод заметок и незавершённых форм заранее копируется в локальный журнал. Дождитесь **«Черновик защищён на устройстве»**: это отдельный статус от обычного сохранения. После перезапуска **«Аварийные черновики»** предлагают явное восстановление, отдельную копию или выгрузку. Восстановление не подтверждает результат и не начисляет очки. Ветки двух вкладок сохраняются отдельно; конфликт редакций не перезаписывается молча. После импорта копии прежнего города доступны для выгрузки, но не для автоматической записи в новый город.

Изображения страхуются до основной записи. При ошибке обоих способов сохранения **«Выгрузить текущий ввод»** скачивает текст и уже подготовленные оригиналы из редактора. Если загрузка ещё готовится, дождитесь её завершения. Закрытие до подтверждения страховки, очистка данных браузера, отказ диска и удаление профиля не гарантируют восстановление. Локальный журнал не заменяет внешний архив и не включается в полную копию города.

Полный экспорт теперь **ZIP v3**: до **256 MiB** архива и **512 MiB** распакованного объёма; JSON до **32 MiB**, PNG/JPEG/WebP до **5 MiB** каждый, до 1000 изображений. Старые ZIP v1/v2 принимаются с прежними пределами 64/128 MiB. Пакеты `.materials.zip` сохраняют прежние ограничения. Изменение, превышающее допустимый объём полного архива, не записывается; уменьшение уже слишком большой старой заметки разрешено для её исправления.

В настройках можно сначала просмотреть **неиспользуемые изображения**, затем явно удалить показанные оригиналы. Перед удалением повторно проверяются ссылки и город; активный редактор в любой вкладке блокирует очистку. Без Web Locks очистка недоступна. Заметки, результаты и оплаченные объекты не удаляются. Проверьте резервную копию перед очисткой.

Скачивание не считается проверенным резервированием. Выберите сохранённый файл через **«Проверить архив без замены»**: приложение проверит структуру, изображения и совпадение с городом. Дата проверки и устаревание копии видны рядом с резервированием. Аварийный ввод проверяется и выгружается отдельно.

Привычка и сокращаемая привычка третьего этапа могут приобрести **сад, двор или павильон** за текущую стоимость новой постройки (по умолчанию 3 очка своего направления). Покупка сохраняет стоимость, правило и подтверждённое основание. Выбор места выполняется отдельно; Escape, снятие, перенос и undo/redo не отменяют владение и не возвращают очки. Один оплаченный объект размещается один раз, повторное размещение бесплатно. Флажок отличает дополнение от бесплатного декора; его собственный вид не подменяется третьим этапом дома привычки. Старые награды и предел трёх этапов сохраняются.

### Город на первом плане

«Продолжить» и «Привычки сегодня» изначально компактны. В них доступны последнее исследование и до трёх привычек; кнопки «Развернуть…» открывают полный контекст. Рядом с привычкой виден сохранённый итог: ○ нет записи, ⋯ черновик, ✓ +N начислено, ✓ 0 подтверждено без награды. Полное объяснение доступно при наведении и в развёрнутом списке.

**«Мои постройки»** показывает здания прогресса без дальних деревьев и границ районов. **«Показать застройку»** учитывает все объекты, **«Вся карта»** — карту целиком. В списке районов **«На карте»** явно фокусирует выбранный район. Сохранение заметки само камеру не двигает.

Из здания привычки можно выбрать **«Отметить сегодня»**; вход ничего не создаёт. Короткий вид оставляет собственный результат, тип с явной наградой, значение и подтверждение цели. **«Подробная запись»** открывает название, дату, минуты и связанные материалы; переключение не теряет ввод. Начисление по-прежнему одно на локальную дату, подтверждённый нулевой день нельзя наградить повторно.

После успешного подтверждения открывается сохранённый итог дня: дата, фактические очки и версия правила, переход к развитию здания, его месту или размещению. Третий этап остаётся последним; новые записи продолжают сохраняться по прежним правилам. Новых этапов и валют эта версия не добавляет.

Если оформление здания или района изменили в другой вкладке, старая форма не перезапишет его. Ваш ввод остаётся: скопируйте нужный текст, нажмите **«Загрузить актуальные поля»** и внесите изменения снова. После импорта старая примерка блокируется до явной загрузки актуального состояния; «Строить» начинает новую примерку. Успешный одноразовый перенос возвращает к карте, серийный декор и дорога остаются активными.


### Быстрый поиск и «Сегодня»

**«Найти в городе»** ищет направления, исследования и материалы по названиям, тексту заметок и тегам. Можно включить архивные направления. В строке видны тип и путь владельцев. `Ctrl/Cmd+K` открывает поиск вне текстовых полей, стрелки выбирают результат, Enter открывает, Escape закрывает с возвратом фокуса. Открытие поиска не закрывает редактор. **«Продолжить исследование»** и **«Найти здание»** — отдельные действия; отсутствие постройки не мешает материалам. Для длинного списка есть полная библиотека. В истории и A/B поиск недоступен до выхода из просмотра.

**«Сегодня»** показывает активные привычки и сокращаемые привычки по дате и часовому поясу города. Список можно свернуть; первые три строки дополняются кнопкой остальных. Статусы различают отсутствие записи, черновик, подтверждённый день без очков и начисленную награду. Выбор строки открывает настоящую форму, ничего не подтверждая. Расписание — ваш текстовый ориентир. Достижение цели отмечаете сами. Открытая форма сохраняет дату и часовой пояс; после полуночи предлагает начать новую запись за сегодня. Нулевая подтверждённая награда закрепляет день по прежним правилам.

### Незавершённые формы и выгрузка материалов

При уходе из изменённых полей исследования, следующего вопроса или результата приложение сначала сохраняет заметку и ждёт изображения, затем предлагает **«Сохранить и продолжить»**, **«Остаться»**, **«Не сохранять»**. Результат при таком сохранении остаётся черновиком без награды. Ошибка останавливает переход; если часть форм уже сохранена, сообщение это объясняет. Собственная архивация результата не мешает дальнейшим дополнениям. Конфликты двух вкладок не перезаписываются молча.

При импорте из другой вкладки несохранённый текст форм доступен для копирования/выгрузки рядом с прежним восстановлением заметки и изображений. Это память текущей вкладки. Beforeunload запрашивает стандартное предупреждение браузера, но не гарантирует восстановление после закрытия, reload, сбоя или отключения питания. Сохраните или выгрузите нужный ввод до выхода.

**«Выгрузить заметку»** и **«Выгрузить материалы исследования»** создают `.materials.zip`: README с контекстом и следующим вопросом, Markdown, точный JSON каждой текущей заметки и только используемые исходные изображения без повторов. Сначала сохраняются изменённые материалы. Пакет предназначен для чтения и ручного переноса, **не для импорта города**. Код и безопасные ссылки сохраняются, HTML экранируется. Не представимые в Markdown элементы (например, подчёркивание) отмечаются предупреждением; исходный JSON сохраняет их. Пределы: 32 MiB текстов/JSON, 64 MiB ZIP, 128 MiB распакованного объёма, до 5000 заметок и 1000 изображений по 5 MiB. Загрузка файла браузеру не означает, что он уже сохранён на диске: проверьте загрузки.

В боковой панели **«Копия и проверка архива»** позволяет скачать прежний полный `.progresscity.zip` и проверить выбранный архив без замены базы. Восстановление остаётся отдельным подтверждаемым действием в настройках.

### Продолжить исследование

На главном экране блок **«Продолжить»** предлагает до трёх исследований активных учебных направлений. Порядок зависит от сохранённых изменений заметок и подтверждений результатов. Подпись даты объясняет, что произошло; просмотры и декор на порядок не влияют. Блок можно свернуть. Пока нет материалов или подтверждений, показано пустое состояние.

**«Продолжить»** открывает исследование и последнюю изменённую заметку в расширенном рабочем виде. Вход ничего не создаёт и не начисляет. **«Новая заметка»** создаётся только явным действием. Можно работать без здания или после его снятия; **«Найти на карте»** — отдельный переход. В контексте доступны следующий вопрос, последний подтверждённый результат и связанные с ним материалы.

**«Рабочий вид» / «Свернуть рабочий вид»** меняют размер того же редактора. **«Вернуться в город»** сохраняет заметку и закрывает панель. Переход ждёт загрузку изображений; при ошибке остаётся в редакторе. Неудачную загрузку можно повторить или явно отменить перед выбором другого изображения.

После **«Зафиксировать результат» → «Подтвердить результат»** можно оставить следующий вопрос. Нажмите **«Сохранить следующий вопрос»** отдельно: вопрос необязателен и не приносит очков. Если он не записался, результат уже подтверждён; повторите только сохранение вопроса. При конфликте двух вкладок ваш текст остаётся в поле, актуальный вопрос загружается явной кнопкой. При уходе из формы приложение предложит сохранить вопрос; reload без сохранения может потерять его.

После перезагрузки сохранённые заметки и вопрос доступны через тот же блок. Его свёрнутость и рабочий вид не сохраняются. Исторические снимки и A/B остаются только для чтения. На узком экране контекст и редактор расположены друг под другом; панель прокручивается.

### Читаемый город

**«Показать застройку»** подбирает обзор по реальным границам зданий и районов, включая крыши. **«Вся карта»** показывает всё поле отдельно. Камера не меняется при сохранении заметки.

**«Подписи: авто»** оставляет названия, которые помещаются без пересечений. **«Выбор / наведение»** показывает только нужное сейчас имя. Выбранный видимый объект имеет приоритет над наведённым, остальные названия скрываются при тесноте или отдалении. Небольшое движение камеры сохраняет допустимые позиции подписей. Длинные имена сокращены только на карте: полное имя доступно в панели и при наведении на здание.

Скрытая подпись не мешает нажать на постройку; направления остаются доступны через панель. В сравнении A/B действуют те же правила, а полный список изменений сохраняется. Исторические контуры помечены **A** и доступны через список. На узком экране закройте боковую панель, чтобы рассмотреть карту. Переключатели обзора и подписей не меняют данные и историю отмены.

### Визуальный конструктор

В **«Строить»** выберите карточку объекта: она показывает архитектуру и размер участка. Для существующего здания откройте **«Оформление и перенос»**. Карточки доступны через Tab и стрелки/пробел; выбранный вариант отмечен рамкой и галочкой. Крупный предпросмотр использует ту же графику, что карта.

Кнопки **1/2/3** позволяют примерить этапы. Будущий этап подписан **«только просмотр»**: на карте остаётся фактически заработанный этап исследования или привычки. Выбор типа и просмотр ничего не начисляют и не тратят.

Выберите готовую палитру или введите **свой акцент #RRGGBB**, например `#327A91`. До **«Сохранить оформление»** или подтверждённого размещения примерка не меняет город. **«Сбросить примерку»** возвращает сохранённый вариант. Сохранённое оформление можно отменить/повторить как обычную планировку; цвет сохраняется после перезагрузки и переноса через ZIP.

**«Выбрать место на карте»** или **«Перенести на карте»** показывает полупрозрачное здание с заработанным этапом. Знак × и пояснение обозначают занятое место или выход за карту. Escape отменяет инструмент без записи. При изменении типа, цвета или имени активный инструмент отменяется: выберите его снова, чтобы разместить новый вариант. Декор остаётся серийным, перенос — одноразовым.

Планировка не показывает наградный эффект. Эффект роста появляется только после сохранённого улучшения и отключается при уменьшенном движении в настройках приложения или системы.

### Мой путь: раньше и сейчас

Откройте **«История»**. Выберите **A — сохранённый снимок**, **B — другой снимок или текущий город**, затем нажмите **«Сравнить город»**. У каждого состояния показаны его настоящее название и время. Текущий город фиксируется при открытии; изменения из другой вкладки попадут в B только после **«Обновить текущее состояние»**.

Переключайте **«Было»**, **«Стало»**, **«Показать изменения»** на одной карте: положение камеры сохраняется. **«Фокус на изменениях»** охватывает старые и новые места объектов. Значки и подписи различают появление на карте, снятие, перенос, этап и оформление; один объект может иметь несколько признаков. Переключатель декора скрывает его отметки и строки, включая районы. Полные виды города A/B сохраняются. Снятые объекты и прежние позиции обозначены историческими контурами; они не выбираются на карте, но доступны в списке изменений.

Выберите изменившуюся учебную постройку на карте или в списке. Панель покажет этапы A/B и существующие события между временами состояний. Если у события есть связь с результатом и заметками, можно открыть эти материалы. Ниже отдельно доступны текущие материалы исследования. Заметки, включая изображения, показаны **в текущей редакции, только для чтения**. Отсутствующие связи и прошлые тексты не восстанавливаются. Повторное размещение того же исследования не считается новым знанием.

Сравнение не меняет город: строительство, перенос и отмена/повтор планировки отключены. Перед входом заметка сохраняется; при ошибке вход останавливается, текст остаётся в редакторе. Незавершённая дорога или размещение отменяются. **«Выйти из сравнения»** возвращает обычный режим и прежнюю камеру; история отмены сохраняется. Импорт города сбрасывает сравнение, в том числе при импорте из другой вкладки. На узком экране закройте боковую панель для просмотра карты; кнопка **«Список изменений»** откроет её снова.

### Удобная планировка

В **«Строить»** выберите дорогу и нажмите **«Выбрать место на карте»**. Зажмите левую кнопку мыши, проведите маршрут и отпустите: вся новая дорога сохранится одним действием. Зелёные клетки свободны, синие уже содержат дорогу, красные запрещают весь маршрут. При пересечении существующая дорога сохраняет своё оформление.

Деревья, парки и площади можно ставить несколько раз подряд тем же инструментом. **Escape** или **«Завершить инструмент»** возвращает обычный выбор зданий. Правая кнопка мыши перемещает камеру во время размещения. Перенос существующего объекта и размещение учебного здания заканчиваются после одного успешного действия.

Кнопки **«Отменить» / «Повторить»** находятся на карте. Сочетания: **Ctrl/Cmd+Z**, **Ctrl/Cmd+Shift+Z**, **Ctrl+Y**. Они работают только вне полей ввода и редактора заметки. Отмена затрагивает размещение, перенос, оформление, снятие объектов и районы; целый жест дороги — одна команда. Очки, купленные постройки исследований, занятия, заметки и этапы остаются прежними.

История хранит последние **100 действий этой вкладки**, сбрасывается после перезагрузки или импорта. Новое успешное изменение убирает возможность повторить отменённые действия. Отмена последовательная: сначала отменяются более поздние действия. Если другая вкладка изменила объект или заняла место, отмена/повтор сообщает о конфликте и ничего не перезаписывает. На узком экране закройте боковую панель, чтобы пользоваться картой и кнопками отмены.

### Материалы и развитие

1. Назовите город и первое направление: появится одна мастерская. Или восстановите свой ZIP со стартового экрана.
2. Нажмите на здание или направление слева. Создайте заметку, добавьте текст, код, ссылку, теги и изображения.
3. Нажмите в редакторе **«Зафиксировать результат»**: заметка сначала сохранится, направление, исследование и материал уже выбраны. Напишите вывод и подтвердите его. Во вкладке «Результаты» также можно сохранять черновики и дополнять записи; повторное подтверждение не выдаёт новую награду.
4. Выберите развитие: улучшить существующий объект или построить новый. Баланс общий для направления, у каждого исследования собственные три этапа. Первое улучшение стоит 3, второе — 6 очков; **новая постройка стоит 3 очка**. Стоимости меняются в настройках только для будущих событий.
5. Для расширения раскройте **«Новое исследование в этом направлении»** и задайте название. Заметки доступны сразу, до покупки постройки. После оплаты выберите шаблон и место на карте. Одному исследованию соответствует одно здание; в направлении их может быть несколько. Снятие и повторное размещение, оформление и декор бесплатны.
6. «Районы» создаёт и меняет прямоугольные зоны. «Библиотека» ищет по названию/тексту и фильтрует по направлению/тегу.
7. «История» показывает начальное состояние, автоматические снимки после улучшений и ваши ручные снимки. Это история города; тексты заметок открываются в текущей редакции.
8. Регулярно сохраняйте `.progresscity.zip` в настройках. Импорт полностью проверяет архив, затем запрашивает подтверждение замены и предлагает экспорт текущего города.

При нажатии на постройку открываются материалы её исследования. Для общей коллекции включите «Все материалы направления» либо используйте библиотеку. В блоке «Вопрос и название исследования» можно сохранить следующий вопрос, а «Почему выросла постройка» показывает расходы и связанные результаты/материалы. Этапы отражают ваши действия, а не объективное измерение знаний.

Старая локальная база обновляется автоматически: начальное исследование получает прежний этап, здание, заметки и результаты. Сохраняются баланс, изображения и исторические снимки. Следующее обновление до БД v3 добавляет только служебные таблицы восстановления; прежние строки не пересчитываются. ZIP v1/v2 читаются; новый экспорт имеет версию **v3**. Старое приложение не сможет открыть ZIP v3 или обновлённую базу. Сохраните отдельную копию прежнего ZIP перед обновлением. Привычки и сокращение привычек сохраняют прежние правила.

Перед обновлением проверяется весь будущий архив: JSON в новом формате (до **32 MiB**), все изображения, manifest и служебные данные ZIP (вместе до **64 MiB**). Если любой предел превышен, старый ZIP не заменит текущий город, а обновление локальной базы полностью отменится. На экране отказа указана причина и есть **«Скачать старый город»**: это полный архив **v1** с заметками, изображениями и историей. Не очищайте данные браузера. Сохраните архив, откройте его в прежней версии приложения (до итерации кварталов, коммит `0cc60ad`), самостоятельно освободите место и повторите обновление. Текст и изображения автоматически не удаляются; простой повтор загрузки без изменения объёма не устранит отказ.

Камера: перетаскивание мышью, колесо для масштаба относительно указателя, кнопки `+`/`−`, «Показать застройку» и «Вся карта». В режиме размещения средняя/правая кнопка перемещает камеру. **Escape** отменяет размещение. Когда canvas в фокусе, работают стрелки и `+`/`−`. Координаты клеток — от 0 до 39.

Сохранение заметок происходит через 500 мс после ввода и принудительно перед переходом. При ошибке не закрывайте вкладку: текст остаётся в редакторе, доступен повтор сохранения. При конфликте двух вкладок можно сохранить свою редакцию отдельной копией. Неподтверждённые формы результатов сохраняйте кнопкой «Сохранить черновик».

Имя и следующий вопрос исследования сохраняются отдельной кнопкой. Если эти поля изменились в другой вкладке, сохранение не перезапишет чужую версию: скопируйте нужный текст и нажмите «Загрузить актуальные поля». Несохранённые формы исследования и результата не переживают закрытие страницы.

Пока создаётся конфликтующая копия, редактор временно блокирует ввод и ждёт завершения загрузки изображения. При ошибке он снова доступен, черновик остаётся.

Если город восстановили из архива в другой вкладке, появляется «Несохранённый материал». Кнопка «Выгрузить черновик с изображениями» сохраняет отдельный ZIP с `note.txt`, `note.json` и исходными изображениями. Это материал для ручного переноса, **не архив города для импорта**. Откройте выгруженный ZIP и убедитесь в сохранности перед удалением черновика из памяти. Черновик живёт только в текущей вкладке: перезагрузка, закрытие или сбой браузера могут его потерять.

Экспорт и импорт имеют одинаковые пределы: 32 MiB UTF-8 для данных и 64 MiB для всего ZIP. В настройках показаны объёмы текста и всех изображений, включая неиспользуемые, и предупреждение при приближении к пределу. Отказ экспорта не удаляет город.

Для привычек расписание и количественная граница служат личным ориентиром. Достижение цели отмечаете вы сами. Нет штрафов и обязательных серий. Награда — максимум раз на направление и сохранённую локальную дату; дата закрепляется при первом сохранении. Подтверждённые записи можно дополнять и архивировать, но прежние награды не пересчитываются.

## Проверки

```powershell
npx playwright install chromium
npm run lint
npm run typecheck
npm run test:unit
npm run test:e2e
npm run build
npm run test:preview
npm run test:launcher
npm run perf:report -- after
```

Playwright поднимает отдельный dev-server на **127.0.0.1:4173**, использует одноразовые контексты Chromium и собственные тестовые базы. Настоящий пользовательский профиль не используется. Повторная установка браузера нужна только при его отсутствии или обновлении Playwright. В этой среде вместо `npx` можно выполнить `node node_modules/@playwright/test/cli.js install chromium`.

После сборки `npm run test:preview` отдельно запускает собранный `dist` на **127.0.0.1:4174**: материалы и прогресс, расширение квартала и ZIP, границы миграции, проведение дорог, серийный декор, отмена/повтор, текстовый undo и сброс истории при импорте. Также проверяются сравнение города, связанные материалы, неизменность данных, камера, фокус, пустое состояние, явное обновление и сброс сравнения после импорта из другой вкладки. Конструктор проверяется через карточки, будущий просмотр, собственный цвет после reload/ZIP, заработанный этап и узкий экран. Для читаемого города проверяются обзор мастерской, переключение подписей, выбранное имя при отдалении и изменение размера до 390×844. Прогоны e2e и preview выполняйте последовательно.

Сквозные сценарии пакета используют архив, созданный кодом предыдущей версии `33a7f9e` в отдельном профиле. `pretest:e2e`, `pretest:preview` и `pretest:launcher` генерируют его локально через `scripts/daily-fixture.mjs`; нужна Git-история с этой версией. Фикстура и временные проекты остаются в `.tools/` и не коммитятся. Preview дополнительно проверяет граф статических зависимостей отложенных модулей. Windows launcher проверяется на отдельном 45173, генератор фикстуры — на 4187, замер — на 4186; все серверы завершаются после своих проверок. Выполняйте наборы последовательно.

`npm run preview` — технический просмотр `dist`, обычно на другом порту. Для повседневной работы с прежним городом используйте Start и прежний origin 5173. [Матрица приёмки](docs/DAILY_RELEASE_REVIEW.md), [отчёт](docs/REVIEW_REPORT.md), [замеры загрузки](docs/PERFORMANCE.md).

## Ограничения MVP

- Настольный Chromium с WebGL. На узком экране панель занимает большую часть карты; полноценное мобильное редактирование не входит в MVP.
- При обзоре далёких районов постройки становятся маленькими; для деталей приблизьте нужную область. Подписи скрываются при тесноте, но объекты остаются доступны. Режим подписей действует до перезагрузки; история текстов и версии графического стиля не сохраняются.
- Карта 40 × 40, три архитектурных шаблона с тремя этапами, пять палитр и собственный акцент #RRGGBB. Старые снимки используют сохранённые тип, цвет и этап с общей актуальной графикой. Нет 3D-вращения, транспорта, облака, синхронизации, аккаунтов и PWA.
- Изображения PNG/JPEG/WebP до 5 MiB; SVG, PDF и другие файлы не загружаются. Внешние источники можно хранить безопасными ссылками. Код не выполняется.
- Заголовок/тег до 250 символов, до 100 тегов; текст заметки/результата до 200 000 символов. Архив: до 64 MiB, распакованный объём до 128 MiB, `data.json` до 32 MiB, максимум 1002 ZIP-файла. Подробные лимиты сущностей — в ARCHITECTURE.md.
- Локальная база не зашифрована и не является резервной копией. Очистка профиля, приватный режим, сбой диска или закрытие вкладки до окончания записи могут привести к потере данных. Экспорт — пользовательская резервная копия.
- Расписание привычки хранится текстом, без уведомлений и автоматической оценки поведения. Подтверждение честного дня без достижения цели выдаёт 0 и закрепляет запись; исправление не пересчитывает награду.
- Нет истории редакций заметки, объединения архивов и автоматического разрешения конфликтов текста. При конфликте предлагается отдельная копия.
- Сравнение хранится только в памяти вкладки. Оно показывает сохранённые состояния и события между их датами, но не восстанавливает старый город и не доказывает причины изменений, если у событий нет таких связей.
- Существующие заметки не переносятся между исследованиями; их связь закреплена. Нет удаления исследования или возврата потраченных очков. В исторических событиях старой версии не было точной ссылки на результат, поэтому она не выдумывается при миграции.
- Неиспользуемые изображения пока остаются в базе и архиве, чтобы не удалять материалы неявно. Большие личные библиотеки и длительное использование месяцами не проходили нагрузочную приёмку.
