# Roadmap к стабильной локальной версии

29.10.2026. Основание: MVP_SCOPE, последующие согласованные итерации и аудит `.tools/full-audit/20261004T171206Z-3cb2c20`. Базовый SHA: `3cb2c20`. Существующее приложение сохраняется; экономика, схема БД, формат городского ZIP, личный origin и материалы не меняются.

## Текущий этап: стабилизация

- [x] R1. Закрыть PC-AUD-001: optimistic conflict/epoch в updateTrack и форме, сохранение локального ввода и явная загрузка актуальных полей; проверить два соединения, две вкладки, повтор сохранения, архивирование и импорт same-ID.
- [x] R2. Закрыть PC-AUD-002: bounded проверка EOCD/центрального каталога и соответствия локальным записям до прежней ограниченной распаковки; сохранить STORE/DEFLATE/v1/v2/stream descriptors и отказ без изменения города.
- [x] R3. Закрыть PC-AUD-003: читаемый muted-текст, регрессия computed contrast, desktop/narrow интерфейс.
- [x] R4. Штатные регрессии и последовательные lint → typecheck → unit → e2e → build → preview → Windows launcher. Сохранить первые ошибки, фактические логи и изображения с синтетическими данными.
- [x] R5. Доступная Windows-приёмка: нативный beforeunload в отдельном профиле, аппаратный GPU при доступности, готовый dist/Stop–Start. Открытие системного браузера не должно затронуть личный профиль; при невозможности изоляции оставить ручным пунктом.
- [x] R6. Согласовать STATUS, REVIEW_REPORT, README и архитектурные решения с результатами, Git-передача по standing-разрешению AGENTS, фактический SHA/remote HEAD фиксируются итоговым сообщением. Без PR/деплоя.

Критерий завершения этапа: исправленные три дефекта, регрессии в штатном наборе, фактические результаты проверок, отсутствие ложных PASS по недоступным сценариям.

## После технической приёмки: повседневная проверка

- [ ] Несколько настоящих занятий пользователя: открыть город → продолжить материал → подтвердить результат → оставить вопрос → вернуться позже → восстановить отдельную тестовую копию из архива. Это нельзя заменить синтетическими тестами или выдумать за пользователя.
- [ ] Собрать конкретные неудобства планировки/поиска/редактора и определить следующую ограниченную итерацию.

## Предложения для отдельной следующей итерации

Постоянные аварийные черновики; безопасная очистка неиспользуемых изображений; контроль актуальности резервирования. Сейчас recovery несохранённого ввода находится в памяти вкладки. Эти предложения не считаются реализованными и не меняют контракт текущей БД автоматически.

## Только при распространении другим людям

Установка без ручной подготовки среды, версии/CHANGELOG, CI и выбранная владельцем лицензия. Выбор лицензии и способа распространения требует решения владельца. Для личной версии существующие Prepare/Start/Stop остаются рабочим способом запуска.

Backend, аккаунты, облако, AI, мобильная упаковка и 3D не являются условиями завершения локальной версии. Расширение каталога/карты выбирается по результатам пользования.
