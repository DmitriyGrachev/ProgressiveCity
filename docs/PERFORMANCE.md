# Исторические измерения — 04.10.2026

Измерено заново до изменений (`33a7f9e`) и после окончательной сборки пакета. Windows, Node 22.23.2, Chromium 153.0.8010.12, headless SwiftShader, 1440×1000. Одинаковый скрипт и набор данных. По три запуска каждого состояния, новая одноразовая browser context на запуск, HTTP cache отключён через CDP; тестовые серверы других наборов завершены. Это не замер аппаратного GPU пользователя.

Команда до изменений: `node scripts/perf-report.mjs baseline`; после окончательного build: `npm run perf:report -- after` (в этой среде через `node .tools/package/bin/npm-cli.js`). Скрипт запускает Vite preview только на 127.0.0.1:4186 со strict port и останавливает его в finally. Требуются уже установленные Playwright/Chromium. Личные 5173 и профиль не используются.

Набор: пустой onboarding; наполненный город — одна мастерская, одно исследование, 100 синтетических заметок примерно по 4500 символов. Время от navigation start до доступного onboarding или canvas с постройкой. После подготовки данных измеряется reload с отключённым HTTP cache. JS — реально полученные ответы начальной загрузки до networkidle, gzip вычислен `zlib.gzipSync` по тем же байтам. Это оценка сжатия: preview передаёт несжатую статику. Числа gzip в этой таблице получены одинаковым способом и могут отличаться от оценок Vite. Полные локальные сырые отчёты с каждым запросом и каждым asset: `.tools/perf-baseline.json`, `.tools/perf-after.json` (игнорируемые, без личных данных).

Полный набор JS вырос на **33 244 bytes** из-за новых возможностей; уменьшение одного index не выдаётся за уменьшение всего приложения. На начальной загрузке обоих состояний **не запрашиваются** NoteEditor, BuildPanel, Settings, backup, materials. Общие archive-format/attachments/ui уже входят в начальные 11 запросов, поэтому они включены в реальные суммы выше. Наполненный город дополнительно запрашивает Pixi init и browserAll. WebworkerAll не запрашивается ни в одном из этих сценариев.

Отложены только необязательные модули. Tiptap-схема нужна синхронной валидации и миграциям; она не удалялась и не подменялась облегчённой проверкой. CityCanvas оставлен eager: один renderer и надёжная общая зависимость для retry. Manifest `chunks.json` содержит соответствие исходных entry и локальных assets. `scripts/check-build-graph.mjs` перед preview подтверждает, что вся transitive static closure каждого из пяти optional entry уже загружена начальным графом: при повторе entry с новым query нет отвергнутой незагруженной общей зависимости в ESM-кеше.

На dist действительно воспроизведены отказ и повтор загрузки редактора, а также отказ materials при работающем редакторе с последующим продолжением текста и выгрузкой. Нет автоматического reload. Дополнительно: один canvas/editor, отсутствие scene updates при заметках/поиске, image URL остаётся прежним при поиске и освобождается при закрытии редактора. CityEngine.setBusy отделяет блокировку взаимодействия от перестройки графики. Синхронное ядро и гарантии сохранения не ослаблены.

Предупреждение Vite о chunks больше 500 kB осталось для index/archive-format. `chunkSizeWarningLimit` не менялся. Бесконечная оптимизация или переписывание хранилища не проводились: обязательный результат F6 — измеренный ограниченный split и проверенное восстановление после отказа.
