# Мой путь — сравнение города раньше и сейчас

Задание пользователя, 20.09.2026. Существующий город, один WebGL canvas, без изменения экономики, Snapshot/IndexedDB/ZIP, без восстановления старого состояния и редакций заметок.

A — сохранённый снимок. B — снимок или согласованно считанный текущий город, фиксируемый на момент открытия. «Обновить текущее состояние» — единственное обновление B в открытом сравнении. Названия и время A/B показываются явно. Можно выбрать одинаковые снимки или обратную хронологию; различия направлены от A к B.

Чистая функция сопоставляет учебные здания по learningObjectId, привычки по trackId, декор по ID размещения. Независимые признаки: появилось/снято с карты, этап, перенос, оформление (имя/цвет/шаблон/размер). Повторное размещение одного исследования с другим ID не означает новое знание. Зоны районов сравниваются по ID как декоративная планировка. Фильтр скрывает маркеры/строки декора и районов, оставляя полные виды A/B.

«Было», «Стало», «Показать изменения» используют одну камеру; последний режим показывает B с маркировкой и явно историческими некликабельными контурами снятых/старых позиций. Легенда и текстовые признаки дополняют цвет. Фокус охватывает исходные и новые места видимых изменений. Выход восстанавливает прежнюю камеру (с поправкой на размер окна).

При входе используется существующий переход с ожиданием сохранения заметки; неудача удерживает черновик. Незавершённый инструмент прекращается до входа. Сравнение только для чтения: навигация к формам изменений отключена, материалы читаются в отдельной панели, undo/redo запрещён, его стеки не меняются. Импорт с другим epoch сбрасывает сравнение; механизмы спасения черновиков сохраняются.

Панель изменившейся постройки показывает этапы A/B, существующие события этого владельца между временами состояний и реальные ссылки activityId/sourceActivityId → noteIds. Отдельно доступны текущие материалы владельца. Заметки явно подписаны как текущая редакция. Нет связи/событий — честное пустое состояние. Сохранение заметки в другой вкладке не перестраивает сцену сравнения.
