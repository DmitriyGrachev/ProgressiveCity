# Продолжить исследование — 02.10.2026

Над картой — компактный сворачиваемый блок до трёх исследований активных skill/project-направлений. Чистая функция использует сохранённые updatedAt заметок и createdAt событий подтверждения с реальной связью на confirmed Activity. Последний результат определяется по времени подтверждения, а не создания черновика. При равной дате — стабильные ID; причина даты видна пользователю. Нет ни заметок, ни подтверждений — честное пустое состояние, без выдуманного прошлого. Пустая сохранённая пользователем заметка считается сохранённым материалом.

Продолжение после flush текущего редактора читает актуальные заметки/исследование/epoch согласованно, открывает последнюю изменённую заметку, не создаёт ничего. Новая заметка — отдельная кнопка. Здание необязательно. «Найти на карте» — явное отдельное действие. Исторический режим и A/B не предлагают новые редактирующие действия.

Рабочий вид — CSS-расширение той же панели TrackPanel/Library; один NoteEditor и SaveSession остаются на месте. ResearchDetails показывает существующий вопрос, подтверждённый результат и его реальные материалы. Все переходы используют прежний flush, ждут изображения, при отказе оставляют текст. Замена города очищает выбранный контекст, сохраняя RecoveryTray.

После подтверждения ActivityForm предлагает необязательный вопрос. Отдельная форма вызывает прежний updateLearningObject с epoch и expectedFields; не вызывает подтверждение повторно. Сообщения различают сохранённый результат, несохранённый вопрос и конфликт. Перезагрузка сохраняет только подтверждённые записи БД; отдельной учебной сессии нет.
