## Последнее исправление

- Старый ZIP на 1024 байта меньше 64 MiB принимался, но после миграции настоящий exportCity отказывал. Дефект воспроизведён через проектные fflate/Zod/Dexie: до исправления 3 RED / 4 PASS.
- Общий prepareArchive проверяет итоговый JSON (32 MiB), реальные Blob.size, manifest и всю служебную часть STORE ZIP (64 MiB). Ровно предел разрешён; превышение на байт отклоняется.
- Проверка применяется в импорте, перед replaceCity, в native upgrade до записей и при экспорте. В versionchange нет чтения Blob, хеширования или сторонних async-операций.
- При отказе остаются схема v1, индексы, заметки, изображения, события, снимки и epoch. UI различает причины 32/64 MiB; полный старый ZIP можно скачать. Никакого автоматического удаления материалов.
- Восемь новых unit-регрессий: исходное воспроизведение, полный ZIP −1/0/+1 через оба пути, отказ при несовпадении Blob.size. Успешные варианты действительно экспортируются и восстанавливаются; прежние проверки 32 MiB сохранены.
- Оба браузерных сценария параметризованы по JSON/ZIP и выполнены на dev и dist; 200 заметок, 13 корректных синтетических PNG, проверка decode, SHA-256, скачивания и повторного запуска.
- Независимый проверяющий работал только на чтение; существенных замечаний нет. Полный план I1–I4 и прежние G/H — IMPLEMENTATION_PLAN.md. Доказательства, промежуточные неуспешные прогоны и снимки — REVIEW_REPORT.md.

## Работающий продукт и ограничения

Итерация кварталов (21e96d6): несколько исследований с собственными материалами/этапами, общий баланс, новая постройка за 3 очка, результат из заметки, свободное размещение и оформление. Привычки, возвращение к материалам, история и резервирование сохранены. Исправление bffbc26 защищает JSON; текущий проход дополняет его полным размером ZIP.

Формула точна для текущего fflate STORE без extras/comments/ZIP64/descriptors; изменение writer требует пересмотра контракта. Она не ограничивает каждое последующее редактирование, не откатывает уже мигрировавшую v2 и не исправляет повреждённые старые изображения. Старый recovery export соблюдает прежние лимиты. Самостоятельное уменьшение материалов — после резервирования в прежнем клиенте.

Основной JS **1 174.83 kB**, gzip **362.05 kB**; предупреждение не подавлено. Firefox/Safari, аппаратный GPU и долгосрочные квоты не проверены. Нет облака, переноса заметок между исследованиями, удаления исследования или возврата очков. Несохранённые формы и спасённые черновики находятся в памяти вкладки; история не содержит редакций текста.

Зависимости/lockfile, глобальные настройки и sandbox не менялись; Docker и новые загрузки не использовались. Тестовые серверы остановлены автоматически.
