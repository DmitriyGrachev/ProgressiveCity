# Фактический статус Progress City

Обновлено **26 сентября 2026**. «Визуальный конструктор» реализован и проверен поверх `c1bf038`. Границы — CONSTRUCTOR_SCOPE.md; решения — ARCHITECTURE.md; план L1–L5 — IMPLEMENTATION_PLAN.md.

## Реализовано

- Визуальные карточки с участками и клавиатурным выбором; крупная примерка. Три архитектурных типа × три различимых этапа, одна графика для карты, карточек и ghost.
- Пять палитр и собственный #RRGGBB. Примерка локальная; сохранение через существующие команды планировки с undo/redo, reload и ZIP. Будущий этап явно обозначен и не попадает на карту бесплатно.
- Полупрозрачная постройка с заработанным этапом, крест и пояснение коллизии/границы. Один кешируемый ghost движется без перестройки города; дороги, серийный декор и Escape сохранены.
- Эффект роста только после реального сохранённого улучшения, с reduced motion. Размещение/import/reload/undo/redo/A/B его не воспроизводят. Ошибка улучшения не показывает успех и не меняет этап/баланс/события.
- Один WebGL renderer; кеш 96 миниатюр. Ревью выявило удержание GraphicsContext, исправлено явным освобождением, повторное read-only ревью без оставшихся подтверждённых замечаний.

Экономика, исследования, владельцы, footprint, БД v2, ZIP, зависимости и lockfile не менялись. Без Docker, загрузок, глобальных настроек, PR и деплоя. Личный город не использован в проверках.
