# Фактический статус Progress City

Обновлено **2 октября 2026**. «Продолжить исследование» реализовано поверх `3340ef2`. Дизайн — CONTINUE_SCOPE.md, решения — ARCHITECTURE.md, план N1–N5 — IMPLEMENTATION_PLAN.md.

## Реализовано

- Сворачиваемые три недавних исследования активных учебных направлений; порядок по сохранённым заметкам и подтверждениям, понятная дата, честное пустое состояние.
- Безопасное продолжение последней изменённой заметки без создания и награды. Материалы доступны без здания и после снятия. Новая заметка и поиск на карте — отдельные действия.
- Контекст ResearchDetails: следующий вопрос, последний подтверждённый результат и его материалы. Один NoteEditor/SaveSession, расширенный рабочий вид и возврат в город.
- Необязательный вопрос после результата: прежняя команда с epoch/конфликтами, отдельный успех и ошибка, без повторного подтверждения.
- Переход ждёт изображение и сохранение; ошибки удерживают редактор. Retry/discard не теряет нерешённую загрузку. Импорт сбрасывает старый контекст и сохраняет восстановление черновика. История/A/B остаются readonly; сохранение текста не перестраивает город.
- Замечания read-only ревью исправлены, целевые регрессии прошли. Первый полный прогон выявил ожидание открытой библиотеки после импорта и лишнее закрытие обычной панели при фокусе; исправления и полный повтор отражены в REVIEW_REPORT.md.

Экономика, привычки, владельцы, этапы, БД v2, ZIP, зависимости и lockfile не менялись. Без Docker, загрузок, глобальных настроек, PR и деплоя. Все данные проверок синтетические.
