## Решения и ограничения

Спецификация/решения: QUARTER_SCOPE.md; архитектура/миграция: ARCHITECTURE.md; план H1–H4 и G1–G5: IMPLEMENTATION_PLAN.md. Фактический Node этого прохода **22.23.2**, локальный npm **12.0.2**. Зависимости/lockfile не менялись и заново не устанавливались. Docker, глобальные настройки и sandbox не затрагивались.

Основной bundle **1 173.36 kB**, gzip **361.45 kB**; предупреждение >500 kB сохраняется. Firefox/Safari, аппаратный GPU, месяцы работы и максимальные объёмы всех сущностей не проверены. Защита не откатывает уже обновлённые базы v2 и не меняет остальные лимиты архива. Если v1 уже сам превышает лимиты или повреждён, спасательный экспорт также откажет без изменения базы. Уменьшение материалов — только явное действие пользователя в прежнем клиенте после резервирования. Нет переноса заметок между исследованиями, удаления исследования, возврата очков или облака. Несохранённые формы и спасённые черновики находятся в памяти вкладки; история не содержит прошлых редакций текста.

Для запуска из корня: `node .tools/package/bin/npm-cli.js run dev` → http://127.0.0.1:5173/. При наличии npm: `npm ci`, затем `npm run dev`. Всегда сохраняйте один origin; для переноса используйте ZIP. Тестовые серверы остановлены автоматически. Текущие изменения готовы к личной проверке; инструкции отказа миграции — README, доказательства и ограничения — REVIEW_REPORT.md.
