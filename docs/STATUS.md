## Что работает

- Дорога одним жестом: непрерывный маршрут по соседним клеткам, зелёный/красный предпросмотр, синие существующие дороги. Вся новая часть сохраняется одной транзакцией и отменяется одной командой. Любое препятствие или выход за карту запрещает весь жест. Escape и потеря захвата указателя не оставляют частичной дороги.
- Бесплатный декор размещается серийно с отдельными ID; Escape завершает инструмент. Перенос и учебные здания одноразовые, связь с материалами не меняется, копирование купленной постройки запрещено.
- Отмена/повтор переноса, размещения, оформления, снятия и районов. Последние 100 действий в памяти вкладки; после импорта/reload история пуста. Кнопки, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y. Поля ввода и заметки сохраняют собственную отмену текста.
- Ошибка записи не двигает историю и не меняет геометрию. Undo/redo проверяет изменённые другой вкладкой записи и свободное место. Смена epoch проверяется в самой транзакции, подписка сбрасывает активный инструмент.
- Занятия, заметки/изображения, баланс, этапы и оплаченные права строительства не отменяются. Снимки остаются историческими. События планировки имеют нулевую награду.

Спецификация и принятые решения: PLANNING_SCOPE.md, ARCHITECTURE.md; план J1–J4 — IMPLEMENTATION_PLAN.md. Реализация одним исполнителем, независимый reviewer только читал код и повторил 13 unit: подтверждённых новых дефектов нет. Прежние исправления миграции JSON/ZIP сохранены.

## Ограничения и запуск

- История последовательная: сначала отменяются более поздние действия; она не экспортируется и не переживает reload. После отказа дороги повторите жест — выбранный инструмент сохраняется.
- Защита конфликтов значений между вкладками добавлена для undo/redo; обычные формы оформления сохраняют прежнее last-write-wins. Приложение рассчитано на одного пользователя.
- Узкий экран проверен на отсутствие переполнения; для работы с картой нужно закрыть боковую панель. Физический touch, Firefox/Safari и аппаратный GPU не проверены.
- Основной JS **1 185.25 kB**, gzip **365.22 kB**. Предупреждение размера не подавлено. Остальные ограничения MVP/резервных копий — README и прежние разделы REVIEW_REPORT.

Схема базы/архива, зависимости и lockfile не изменены. Без Docker, новых загрузок, глобальных настроек и изменения sandbox.
