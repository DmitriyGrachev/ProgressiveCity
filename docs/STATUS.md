# Фактический статус Progress City

Обновлено: **8 сентября 2026**. Этапы A–E выполнены; рабочий MVP передаётся для личной проверки. Не объявляется production-ready.

## Сделано

- A: React/Vite/strict TypeScript, Dexie v1, старт с одной мастерской, заметки, подтверждения, отдельные улучшения, восстановление после reload.
- B: PixiJS/WebGL, карта 40 × 40, камера/pan/zoom, hit testing, предпросмотр/коллизии/границы, размещение/перенос/снятие. Три типа зданий × три этапа, имена/палитры, дороги/парк/площадь/деревья, редактируемые районы.
- C: Tiptap JSON и отдельный поисковый текст, стабильные Blob-вложения, ссылки/код/теги, библиотека и поиск. Последовательное автосохранение, flush до перехода, конфликт двух вкладок с отдельной копией. Результаты/черновики/архивирование, привычки без штрафов и с закреплёнными датами, версии правил.
- D: Независимые snapshots, исторический просмотр только для чтения, ZIP с manifest/контрольными суммами/изображениями, проверка до атомарной замены. Стартовый импорт без временного города. Epoch защищает от сохранения старой сессии после восстановления.
- E: Реальные проверки, исправления, независимое read-only ревью, синтетические скриншоты, README, ARCHITECTURE, REVIEW_REPORT.

## Среда и решения

- Исходно были только пользовательские документы; они сохранены. На этапе реализации Git не инициализировался, коммитов/push/PR/деплоя не было. Последующим отдельным запросом пользователь разрешил коммит и push в `DmitriyGrachev/ProgressiveCity`.
- Node **24.19.0**. `npm` в PATH отсутствовал: npm 12.0.2 из официального registry размещён в игнорируемой `.tools/package`. Все зависимости локальные, package-lock.json создан. Глобальные настройки и sandbox не менялись; Docker не использовался.
- React 19.2.8, Vite 8.2.2 + plugin-react 6.1.1, TypeScript 6.0.3, PixiJS 8.20.1, Tiptap 3.31.3, Dexie 4.4.5, Zustand 5.0.15, Zod 4.5.4, fflate 0.8.3, Vitest 5.0.0, Playwright 1.63.0. Проверены официальные документы и peer dependencies. npm install сообщил 0 vulnerabilities.
- Доменные сущности отделены от сцены; state на кадр не записывается. Бесплатное оформление не изменяет баланс. Самостоятельные векторные рисунки, без генерации концепт-арта.

## Ограничения и следующий шаг

Основной bundle около 1.14 MB / gzip 353 kB; оптимизация разбиения не выполнена. Не проверены аппаратные GPU, Firefox/Safari, месяцы эксплуатации, максимальные объёмы данных и чистая установка на другой машине. Расписание привычки текстовое; история не хранит старые редакции заметок. Нет PWA/облака/синхронизации. Неиспользуемые изображения пока сохраняются. Ограничения архивов/материалов подробно перечислены в README и ARCHITECTURE.

Для личной проверки запущен dev-server **http://127.0.0.1:5173/** (сессия 56093 в среде выполнения). Если сервер остановится: `npm run dev` из корня, либо `node .tools/package/bin/npm-cli.js run dev` в текущей среде. Тестовый сервер 4173 управляется test:e2e автоматически. Пользовательский город не создавался. Следующий шаг — пройти свой реальный сценарий и выполнить read-only ревью по `prompts/REVIEW_BEFORE_GITHUB.md`.
