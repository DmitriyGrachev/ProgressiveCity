# Визуальный конструктор города — 26.09.2026

Итерация поверх c1bf038. Цель — наглядный выбор и примерка существующих объектов. Экономика, владельцы, footprints, этапы, БД v2, ZIP и механика покупок сохраняются.

Каталог в BuildPanel: карточки существующих типов, название, участок, видимое выбранное состояние и управление клавиатурой. Крупный предпросмотр с этапами 1/2/3; будущий этап явно подписан как примерка. Размещение получает этап только из сохранённого владельца, а не из переключателя просмотра.

Единственный источник рисунков — city/art.ts. Карта, полупрозрачный объект размещения и растровые изображения каталога вызывают его. Для каталога используется renderer уже открытой карты, результат кешируется с ограничением 96 вариантов по типу/цвету/этапу; участок фиксирован типом. Нет постоянно работающего canvas на карточку. На движении указателя меняется положение одного ghost, город не пересоздаётся.

Стиль остаётся тёплым векторным изометрическим. Мастерская развивается пристройкой и рабочей галереей; библиотека — читальным залом и башенкой; павильон — навесами, опорами и садовой оградой. Три этапа различаются силуэтом и деталями, не только высотой. Старые города и снимки используют сохранённые тип, цвет и этап с обновлённой общей графикой.

Пять готовых палитр и текстовый акцент #RRGGBB. Некорректный ввод объясняется и блокирует подтверждение; примерка не пишет в базу. Сохранение оформления — прежняя команда планировки с undo/redo. Активная примерка отменяется при изменении её параметров; повторный выбор инструмента использует новый вариант, без скрытой записи старого.

Предпросмотр места показывает объект, площадку и текст/крест при коллизии или границе. Сохраняются Escape, дороги одним жестом, серийный декор и одноразовый перенос. Сообщение об успехе появляется после записи. Импорт/reload/undo/redo/A/B не вызывают наградные эффекты; реальное сохранённое улучшение учитывает reduced motion.

Один исполнитель, затем read-only ревью. Реальная приёмка: девять архитектурных вариантов, каталог, ghost, плотный квартал, A/B, цвет после reload/ZIP, отмена без записи, будущий этап, отказ улучшения, заметка без перестроек, клавиатура и узкий экран. Browser-плагина нет: установленный Playwright, одноразовые базы и синтетические материалы. Проверки последовательно lint → typecheck → unit → e2e → build → preview; фактические результаты в STATUS/REVIEW_REPORT. Затем разрешённые коммит и отправка main без force; без деплоя.
