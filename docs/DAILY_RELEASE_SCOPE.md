# Ежедневное использование — дизайн 04.10.2026

BASE_SHA: `33a7f9e1fe57a5001798a23b75bff47a7abfba92`, чистый main; удалённый main совпал. Основание: переданные PROMPT_DAILY_RELEASE.md и ACCEPTANCE.md. Весь пакет F1–F6, без новых зависимостей, экономики, миграции БД, изменения городского ZIP, backend, PWA, AI или деплоя.

- F1: тонкие Prepare/Start/Stop.cmd, Node-скрипты относительно своего корня. Отдельная игнорируемая `.progress-city/` содержит неизменяемые подготовленные сборки и служебное состояние. Fingerprint учитывает исходники, lockfile и конфиги. Prepare строит во временную папку и переключает указатель только после успеха; активный собственный экземпляр сначала требуется остановить. Start не устанавливает/не собирает. Только 127.0.0.1:5173; тестовый порт задаётся явно. Доступен только список файлов сборки, никакого доступа к проекту/профилю. Владение проверяется приватным локальным IPC с криптографическим challenge, не PID/HTTP 200; Stop никогда не убивает PID. Общая блокировка сериализует конкурирующие действия. Readiness сверяет экземпляр; версия видна пользователю. Нет переноса origin или копирования браузерного профиля.
- F4: небольшой реестр участников перехода рядом с прежним callback NoteEditor. Сначала flush заметки с upload/copy, затем один доступный диалог перечисленных изменённых форм: сохранить/остаться/не сохранять. Сохранение результата при уходе создаёт только черновик; вопросы — прежняя команда epoch/expectedFields. Поля блокируются при записи. Неудача оставляет ввод, частичные сохранения учитываются отдельно. На import старый текст удерживается в памяти для копирования/выгрузки без возможности писать в новый epoch; RecoveryTray изображений сохраняется. Beforeunload предупреждает, crash recovery не обещается.
- F2: палитра поверх существующего редактора, без его размонтирования. Чистый поиск по имеющимся данным с устойчивым ранжированием и ограничением выдачи, архивным фильтром и путями владельцев. Кнопка и Ctrl/Cmd+K вне текстового ввода; стрелки/Enter/Escape и возврат фокуса. Материал/продолжение/здание — разные действия с повторной проверкой epoch и владельца. Read-only не обходится.
- F3: компактный сворачиваемый список нескольких активных habit/reduce рядом с «Продолжить», доступ к остальным. Свободное расписание показывается текстом. Локальная дата города, состояние по сохранённым Activity и событию habit:track:date; существующая ActivityForm/команды, никакой оценки выполнения по выбору строки. Открытая дата закреплена, полночь предлагает другую запись. Нулевая награда объясняется до подтверждения.
- F5: `.materials.zip` для чтения: README, Markdown, исходный JSON, только используемые изображения без повторов. Безопасные уникальные пути и экранирование, без HTML/внешних загрузок. Согласованный readonly capture + ограниченная упаковка вне транзакции; повторная проверка epoch до передачи браузеру. Ошибки вложений явные, неизвестные узлы сохраняются в JSON с предупреждением. Backup города и проверка архива переиспользуются отдельно.
- F6: сопоставимые холодные загрузки пустой/наполненной синтетической базы, несколько повторов и медианы, JS/gzip/реальные начальные запросы. Сначала граф импортов; редактор и backup отложены лишь там, где это действительно убирает запросы, без ослабления синхронной валидации. Ошибка optional chunk показывает retry без reload и потери активного редактора. Один renderer/editor, стабильные подписки сцены.

Проверки: отдельные регрессии каждого этапа, Windows launcher с чужим портом/гонками/неудачной подготовкой/переносом в кириллицу и пробелы; S1–S5 из пакета на реальном dist с одноразовыми базами. В конце строго lint → typecheck → unit → e2e → build → preview, затем launcher/perf/сквозная приёмка при завершённых предыдущих серверах. Browser plugin not available: установленный Playwright/Chromium. Личный 5173 в тестах не используется.

Работа ведётся одним исполнителем, read-only reviewer в M6. Обычные обратимые решения принимаются самостоятельно по прямому заданию пользователя; новый worktree и повторные согласования не нужны. Разрешённые commit/push main — только проверенные намеренные изменения, без force/PR/деплоя. Непроверенные строки матрицы остаются PARTIAL/BLOCKED с причиной.
