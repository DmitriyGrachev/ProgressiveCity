Модули: `src/domain` — типы/правила/геометрия; `src/storage` — БД/команды/архив; `src/city` — рисунок и камера; `src/notes` — редактор/сохранение; `src/features` — панели направлений, активностей, истории и настроек; `src/app` — композиция и временное состояние Zustand. Vitest проверяет реальные команды с fake-indexeddb; Playwright — настоящую IndexedDB и WebGL в одноразовых контекстах.

Решения: приложение занимает экран; светлая нейтральная оболочка, зелёная карта, контекстная правая панель. Сгенерированный концепт-арт не используется по заданию. Свободное оформление никогда не меняет баланс. IndexedDB является источником данных, Zustand хранит только состояние интерфейса. Изменения заметок сохраняются последовательно и принудительно завершаются перед навигацией.
