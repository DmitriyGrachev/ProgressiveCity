# Удобная планировка

Согласованное задание пользователя, 19.09.2026: дорога одним жестом с предпросмотром, серийный бесплатный декор, отмена/повтор только планировки.

Решения: маршрут проходит по соседним клеткам, при быстрых движениях промежутки заполняются. Существующие дороги пропускаются; любое другое препятствие или выход за карту запрещает весь жест. Отмена и повтор охватывают размещение, перенос, оформление, снятие объектов и зоны районов. Жест дороги — одна транзакция и одна команда.

История — последние 100 действий текущей вкладки, без сохранения в архив. Новое успешное действие очищает повтор; отказ записи не меняет историю. Импорт с новым epoch очищает команды и активный инструмент. Конфликт отмены/повтора с изменением другой вкладки отклоняется без перезаписи; можно повторить после устранения конфликта. Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y действуют вне полей ввода/редактора. Escape завершает инструмент и отменяет незавершённый жест.

Учебное здание размещается один раз и сохраняет связи. Отмена не пишет в направления, исследования, заметки, вложения, активности или снимки, не отменяет расходы; добавляет только событие планировки без награды. Исторический город остаётся только для просмотра.

Приёмка: две постройки соединить дорогой, поставить несколько украшений, перенести мастерскую и отменить/повторить перенос, отменить целую дорогу через последовательную отмену последующих действий; после перезагрузки геометрия сохранена, материалы/баланс/этапы прежние.
