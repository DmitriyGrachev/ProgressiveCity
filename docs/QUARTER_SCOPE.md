# От мастерской к своему кварталу

Задание пользователя от 19.09.2026: несколько самостоятельно названных исследований/мини-проектов внутри одного учебного направления, собственные материалы и этапы, выбор между улучшением и расширением, результат прямо из заметки. Общий баланс направления; привычки и сокращение привычек работают по прежним правилам.

## Решения

- Учебный объект (`LearningObject`) принадлежит skill/project-направлению. У него имя, следующий вопрос, этап 1–3 и право на строительство. Черновое исследование бесплатно; покупка права на его здание стоит **3 очка** (согласовано пользователем). Стоимость настраивается только для будущих покупок.
- Первое исследование каждого направления доступно бесплатно. При миграции оно получает прежний этап, все заметки, результаты, здание и события улучшений. Его ID равен ID направления (пространства сущностей различны), что обеспечивает детерминированную миграцию любых старых идентификаторов.
- `Track.balance` общий. `Track.stage` используется только привычками; для учебных направлений после миграции равен 1. Рендеринг и улучшения учебных зданий используют исключительно этап объекта.
- Один учебный объект может иметь одну постройку на карте. Купленное право сохраняется при снятии здания: повторное размещение бесплатно. Декор, оформление и перемещение бесплатны.
- Заметка и результат относятся к одному объекту. Библиотека направления объединяет все его материалы. Уже сохранённые связи закреплены, чтобы дополнение результата не переписывало основание начисления.
- Покупка/улучшение, списание и событие выполняются одной транзакцией; повтор команды не списывает повторно. Событие содержит объект, применённую стоимость, версию правил и при наличии ссылку на подтверждённый результат этого направления.
- Старые ZIP v1 полностью проверяются и преобразуются в v2; новый экспорт — v2. Снимки сохраняют исторические этапы, а не текущие значения или редакции текста.
- Нет изменения стека, платных сервисов, Docker, редизайна или публикации.

## Приёмка

Открыть город v1 → новое исследование в том же направлении → заметка с изображением → результат из редактора → выбор улучшить/построить → второе здание на реальном canvas → его собственные материалы → перезагрузка и ZIP-восстановление. Сохранить проверки конфликтов заметок, локального восстановления черновиков, независимости сцены от автосохранения и привычек в двух вкладках.
